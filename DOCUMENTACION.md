# Documentación del Proyecto — Curso Orientativo NTIC

> Documentación general sobre la planeación, desarrollo, herramientas y resultados obtenidos en el proyecto para la materia de **Competencia Digital** (LCC — UNISON).

---

## 1. ¿Qué se desarrolló?

Se desarrolló una investigación acerca de toda la información relacionada con el hardware de las laptops. Los datos obtenidos como resultado de la investigación fueron divididos en varias categorías con el objetivo de que estén organizados de forma clara, entendible y parecida a un formato de curso.

Teniendo la información actualizada y categorizada, se trasladó a un formato de página web. Esto con el objetivo de facilitar la obtención de la información recopilada para cualquier alumno de la carrera que la pueda necesitar o le parezca interesante, así como también para aprender nosotros, los desarrolladores del proyecto, nuevas habilidades que nos pudieran ayudar en un futuro a elaborar mejores proyectos de este estilo.

## 2. ¿Cómo se desarrolló?

Para desarrollar el proyecto, primeramente planteamos una agenda en la que marcamos nuestros tiempos destinados para cada parte de la investigación y elaboración del proyecto, así como la repartición principal de trabajos para eficientar el tiempo y poder entregar un buen producto a tiempo.

Estando ya organizados con los tiempos, creamos la estructura de lo que sería la investigación, la cual es la estructura que se ve en la página web. Una vez teniendo las categorías para la información, se empezaron a llenar con datos actualizados y veraces recopilados a partir de fuentes confiables.

Al llevar un avance de alrededor del **50 %** de la investigación, se empezó a realizar en paralelo la creación de la página web en la que estaría plasmada. Para la elaboración del sitio:

1. **Organización:** Se tomaron como base las categorías en las que se dividió la información para mantener la estructura de la página.
2. **Esqueleto:** Se elaboró la estructura básica de la página para tener toda la información desplegada.
3. **Funcionalidad:** Se desarrolló la parte funcional de los movimientos e interacciones de la página.
4. **Diseño visual:** Finalmente realizamos una lluvia de ideas para el diseño de la web y llevamos a cabo su implementación.

## 3. ¿Qué herramientas y tecnologías se utilizaron?

Las herramientas principales utilizadas para la elaboración del proyecto son:

* **HTML:** Lenguaje de marcado utilizado para estructurar y dar contenido a las páginas web.
* **CSS:** Lenguaje de diseño gráfico para definir y crear la presentación y estilo de un documento estructurado en HTML.
* **JavaScript:** Lenguaje de programación utilizado para dotar de interactividad, dinamismo y lógica a las páginas web.
* **Tailwind CSS:** Framework de CSS basado en clases utilitarias para diseñar interfaces de usuario de forma rápida y personalizada.
* **Vue.js:** Framework de JavaScript progresivo utilizado para construir interfaces de usuario y aplicaciones.
* **Vite:** Herramienta de compilación y empaquetado de próxima generación extremadamente rápida para el desarrollo web moderno.
* **Node.js:** Entorno de ejecución para JavaScript orientado a eventos asíncronos, diseñado para construir aplicaciones de red escalables del lado del servidor.
* **npm:** Gestor de paquetes oficial de Node.js, utilizado para instalar, compartir y gestionar dependencias de código en proyectos.
* **Python:** Lenguaje de programación de alto nivel, versátil y de propósito general, muy utilizado en desarrollo web, análisis de datos e inteligencia artificial.
* **Vercel:** Plataforma en la nube optimizada para alojar sitios web estáticos y aplicaciones web dinámicas con despliegues continuos.
* **Supabase:** Alternativa de código abierto a Firebase que proporciona base de datos PostgreSQL, autenticación y almacenamiento en tiempo real.
* **Git:** Sistema de control de versiones distribuido diseñado para rastrear cambios en el código fuente durante el desarrollo de software.
* **GitHub:** Plataforma de desarrollo colaborativo basada en la web que utiliza Git para el control de versiones y la gestión de proyectos.

## 4. ¿Qué resultados se obtuvieron?

Como resultado de todo lo anterior, obtuvimos una página web completamente funcional, accesible para todos y de código abierto, que tiene como objetivo guiar a los estudiantes de la **Licenciatura en Ciencias de la Computación** que estén buscando un equipo para utilizar durante el transcurso de su carrera con información veraz y actualizada (**2026**).

Además, como resultados secundarios y personales, obtuvimos una gran experiencia de trabajo cercana a lo que sería elaborar un proyecto completo en un entorno real. Descubrimos y desarrollamos nuevas habilidades que nos ayudarán en el transcurso de nuestra carrera de LCC y, como estudiantes de primer semestre, comenzamos a prepararnos con este proyecto para lo que llevaremos a futuro en la licenciatura.
